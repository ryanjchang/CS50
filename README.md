CS50x — Introduction to Computer Science

My problem sets from Harvard's CS50x. Languages used: C, Python, SQL, HTML, CSS, and JavaScript.

Week 0 — Scratch

Project: Scratch (original animation, game, or interactive story)
Covered computational thinking and the fundamentals of programming — functions, variables, conditionals, loops, and events — through drag-and-drop visual programming.

Week 1 — C

Projects: Mario, Cash, Credit
Covered the basics of C, including compiling, command-line arguments, variables, conditionals, loops, and functions, writing programs to build pyramids and validate credit card numbers.

Week 2 — Arrays

Projects: Scrabble, Readability
Covered arrays, strings, and command-line arguments in C, using them to score Scrabble words and estimate a text's reading level.

Week 3 — Algorithms

Projects: Sort, Plurality, Runoff, Tideman
Covered algorithmic thinking, running time, and searching/sorting techniques, implementing several voting algorithms to determine election winners.

Week 4 — Memory

Projects: Filter, Recover
Covered pointers, memory allocation, and file I/O in C, applying them to manipulate image files and recover deleted JPEGs from a memory card.

Week 5 — Data Structures

Project: Speller
Covered dynamic data structures such as linked lists, hash tables, and tries, using them to build a spell-checker optimized for speed.

Week 6 — Python

Projects: Mario, Cash, Credit, Readability, DNA
Transitioned earlier C problems into Python to highlight the language's higher-level syntax and libraries, culminating in a program that identifies people from DNA sequences.

Week 7 — SQL

Projects: Movies, Fiftyville
Covered relational databases and SQL commands like SELECT, JOIN, and CREATE, using them to query a movie database and solve a fictional crime mystery.

Week 8 — HTML, CSS, JavaScript

Projects: Homepage, Trivia
Covered front-end web development, including page structure, styling, and client-side interactivity, building a personal homepage and a trivia game.

Week 9 — Flask

Project: Finance
Covered back-end web development with Python, including routes, templates, sessions, and databases, building a web app that lets users buy and sell stocks.
